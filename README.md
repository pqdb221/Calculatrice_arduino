# Calculatrice_arduino🧮
Calculatrice arduino est un calculatrice qui tourne dans l'arduino et l'afiche dans le moniteur série.
# Utilisation
Branchez l'arduino et téléversez y le code , ouvrez le moniteur série et réglez le sur 9600 bauds envoyez le le calcul en format 1+1.
